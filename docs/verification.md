# 검증 기록

검증일: 2026-11-09. 네이티브 빌드 완료 또는 배포 준비 완료를 의미하지 않습니다.

## 직접 수행한 검사

- Windows cmd.exe + 테스트용 CLI shim: 9/9 통과. 세 CLI의 인자와 stdin 전달, 한글·공백 경로, 특수문자·줄바꿈, 종료 코드 0/7/13 확인. 실제 AI 서비스 호출은 하지 않았습니다.
- 실제 time/store 소스를 별도 임시 하네스로 변환한 검사: 11/11 통과. 시간 검증 7개, 중복 탐지·동시 작업 busy·오래된 응답 차단·실패 처리 4개. Vitest 전체 실행 결과는 아닙니다.
- 로컬에서 사용 가능한 TypeScript 5.9.3과 React/Zustand 타입, 임시 Tauri 선언을 사용한 제한적 strict 검사: 오류 없음. 실제 의존성 설치 후 yarn typecheck가 필요합니다.
- TypeScript 구문 트리 기반 자체 사전 검사: 함수 207개, 인지복잡도 최대 4. 공식 SonarJS 실행 결과와 동일하다고 보장하지 않습니다.
- Prettier: TS/TSX/JS/CJS/CSS/JSON/YAML/Markdown 서식 적용 및 파싱 성공.
- Windows 패키징 PowerShell 구문 검사와 macOS 패키징 bash -n 통과.

## 구조와 성능 변경

스케줄러의 유휴 폴링에서 전체 상태 복제·JSON 직렬화 비교를 제거했습니다. 변경된 데이터만 저장하며, 상태 변화가 있을 때만 UI 이벤트를 보냅니다. 결과 파일 메타데이터를 비교하고 프로세스 생존 확인과 이력 정리를 별도 주기로 수행합니다. 터미널 실행은 상태 mutex 밖에서 처리하고 작업별로 독립 dispatch합니다.

React는 Zustand 선택 구독과 메모화된 목록을 사용합니다. 남은 시간만 공유 타이머에 구독하며 중복 탐지 요청을 합칩니다. 날짜 포매터를 재사용합니다. 실제 앱 전체 CPU·메모리 성능 측정은 아직 수행하지 않았습니다.

복잡도 상한 5를 ESLint SonarJS와 Rust Clippy 설정 및 수동 빌드 CI에 추가했습니다. 두 도구의 측정 방식은 다릅니다. Rust 전체가 상한을 통과했다는 검증은 아직 없습니다.

임시 진단 스크립트, 중복 문서, 캐시, 해석 결과가 없는 placeholder yarn.lock을 삭제했습니다. 테스트는 tests, 필요한 배포 스크립트는 scripts에 유지합니다.

## 실행하지 못한 검사

현재 환경에 Rust/Cargo와 Yarn이 없고 패키지 다운로드가 EACCES로 차단됩니다. 따라서 실제 의존성 설치, ESLint, 전체 Vitest, Clippy, Rust 검사·테스트, Windows EXE 및 macOS APP 빌드는 실행하지 못했습니다. 공식 도구 검사 실패 여부도 아직 알 수 없습니다. GitHub Actions를 실행하거나 원격 저장소에 push하지 않았습니다.

## 플랫폼 수동 검증

Windows 10/11 및 macOS ARM64/x64에서 실제 AI CLI 인증·승인 거부·실패/성공, 외부 터미널 창/출력, 종료 코드, 앱 종료 후 실행 래퍼 생존을 확인해야 합니다. 트레이 숨김/복원·백그라운드 실행·완전 종료, 동시 예약, 절전 복귀·시간대/DST 변경·missed 복구, 데이터 손상·쓰기 실패, 알림 및 Automation 권한도 실제 OS에서 확인해야 합니다.

Warp는 설치 탐지와 실행 지원을 구분하며 현재 실행 어댑터는 지원하지 않습니다. Portable EXE의 다른 PC 이동 실행, WebView2 미설치 환경, 서명·공증은 미검증입니다.
