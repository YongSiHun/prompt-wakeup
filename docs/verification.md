# 검증 현황

기준일: 2026-11-09. 아래 로컬 검사 결과는 네이티브 앱 빌드·배포 성공을 의미하지 않습니다.

## 확인한 항목

| 검사                    | 결과와 범위                                                                                                                                   |
| ----------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| Windows cmd.exe 전송    | Rust의 실제 batch_command 함수를 추출한 회귀 검사 9개 및 Node shim 검사 9개 통과. 한글·공백 경로, 특수문자·줄바꿈, 인자·stdin, 종료 코드 확인 |
| 시간·상태 관리          | 별도 임시 하네스 11개 통과. 실제 AI CLI 호출과 전체 Vitest 결과는 제외                                                                        |
| 제한적 strict 타입 검사 | 로컬 TypeScript·React·Zustand와 임시 Tauri 선언으로 오류 없음. 정식 의존성 기반 재검사 필요                                                   |
| 복잡도 사전 검사        | 자체 TypeScript 구문 트리 검사 최대 4. 공식 SonarJS·Clippy 통과 여부는 미확인                                                                 |
| 패키징 스크립트         | PowerShell 구문 검사와 bash -n 통과. 실제 패키징은 미검증                                                                                     |

## 남은 검증

- CI에서 SonarJS S2201 초기화 오류가 보고되었습니다. TypeScript 전이 의존성과 ESLint·SonarJS 버전을 고정했으나 해결 여부는 아직 확인하지 못했습니다. 인지복잡도 상한은 5입니다.
- 로컬 Cargo 1.99.1 설치를 확인했습니다. Cargo test는 chrono 캐시 부재와 crates.io 연결 차단으로 실행하지 못했습니다. 전체 린트·타입 검사·Vitest·Rust 검사 및 Windows EXE·macOS APP 빌드 결과는 미확인입니다. 최종 판단은 수동 Actions 결과를 기준으로 합니다.
- 실제 OS에서 외부 터미널 표시·출력·종료 코드, AI CLI 인증·승인 거부, 트레이 숨김·복원·종료, 동시 예약·중복 방지, 절전·시간 변경·missed 복구, 저장 실패·손상 복구, 알림·Automation 권한을 확인해야 합니다.
- Portable 이동 실행, WebView2 미설치 환경, macOS ARM64/x64 실행, 서명·공증은 미검증입니다. Warp는 설치 탐지만 지원하며 실행은 지원하지 않습니다.
- 전체 앱 CPU·메모리 성능은 측정하지 않았습니다. 실제 의존성 설치로 Yarn/Cargo 잠금 파일을 생성·커밋하고 재현 빌드를 확인해야 합니다.
