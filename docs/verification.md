# 검증 현황

기준일: 2026-11-09. 아래 로컬 검사 결과는 네이티브 앱 빌드·배포 성공을 의미하지 않습니다.

## 2026-11-17 출력 파일 위치 및 Windows 서명

- 실행 결과 카드에 실제 출력 파일 경로와 UTF-8 텍스트 형식을 표시하고, 파일 열기(Windows 메모장)와 저장 폴더 열기를 추가했습니다. 경로는 프런트엔드 입력 대신 UUID로 백엔드에서 생성합니다.
- Windows workflow는 기본적으로 서명을 필수로 하며, Release 게시는 개발 빌드 옵션과 관계없이 서명을 요구합니다. 인증서 없는 개발 빌드는 signed_build를 해제해야 합니다. 서명 신뢰와 타임스탬프 검증을 추가했습니다.
- 출력 파일 처리의 실제 Rust 모듈을 임시 하네스로 컴파일한 검사 3개, 임시 UI 렌더링·핸들러 하네스 7개, 패키징 PowerShell 구문·미서명 배포 차단 검사 통과. 로컬 의존성 기반 타입 검사 및 기본 ESLint, Rust fmt 검사도 통과했습니다.
- 인증서와 전체 의존성 부재로 실제 서명·패키징·SmartScreen 및 네이티브 파일 열기는 검증하지 못했습니다. 서명된 파일도 평판에 따라 SmartScreen 경고가 표시될 수 있습니다.

## 2026-11-17 화면 및 종료 동작 변경

- 예약 목록과 개수는 대기 중인 작업만 표시하며, 예약 탭의 실행 결과와 실행 환경 표시를 제거했습니다.
- 완료된 실행 결과 삭제를 기록 저장 및 출력 파일 정리와 연결했습니다. 실행 중인 작업은 프런트엔드와 백엔드에서 삭제를 차단합니다.
- CLI 추가·수정 창에서 지원 CLI 이름과 경로를 지정합니다. 제목 옆의 CLI 재탐색은 CLI만 검사합니다.
- 창 닫기 요청 시 취소·트레이 유지·완전 종료를 선택하며, 공통 네이티브 dialog와 카드·버튼·간격 규칙을 적용했습니다.
- 로컬 의존성과 임시 Tauri 선언 기반 타입 검사, SonarJS를 제외한 기본 ESLint, Prettier, Rust fmt 검사 통과. 임시 UI 하네스 6개, 기존 상태·시간 하네스 7개, Windows shim 9개 통과.
- Vitest 전체·Cargo 테스트·네이티브 빌드는 의존성 다운로드 차단 및 Cargo 캐시 부재로 미실행입니다. 브라우저 호스트 오류와 Edge 실행 승인 제한으로 실제 화면 확인도 완료하지 못했습니다. UI 하네스는 서버 렌더링·이벤트 핸들러 수준이며 실제 OS 트레이·종료 검증을 대신하지 않습니다.

## 2026-11-16 앱 내 터미널 변경

- 외부 터미널 실행을 숨겨진 작업 프로세스로 전환하고, stdout·stderr를 실행별 출력 파일에 저장합니다. 예약 화면과 실행 결과 화면에서 전체 출력을 조회하며, 보존 기간 만료 시 출력 파일도 정리합니다.
- 실제 Rust execute 함수를 추출한 로컬 하네스 3개 통과: 한글 stdin·stdout·stderr 보존, stdout·stderr 각각 20만 자 및 비정상 종료 코드, 실행 도중 출력 조회. CLI 어댑터와 입력 검증은 하네스 대역을 사용했습니다.
- 기존 Windows Node shim 검사 9개 통과. 로컬 캐시 TypeScript와 임시 Tauri 선언 기반 앱 소스 타입 검사, SonarJS를 제외한 기본 ESLint 검사, 수정 파일 Prettier 및 Rust fmt 검사 통과.
- 추가한 Vitest UI 회귀 검사와 Cargo 전체 테스트, 네이티브 앱 빌드는 의존성 부재와 패키지 서버 연결 차단으로 미실행입니다. 실제 AI CLI·트레이·재시작 통합 검증이 남아 있습니다.

## 이번 변경의 추가 검증

- 전체 Prettier 3.7.4 적용 및 검사, 전체 Rust fmt 적용 및 검사 통과.
- 캐시된 ESLint 9.39.5·TypeScript parser 8.72.1로 전체 기본 규칙 검사 통과. SonarJS를 제외한 임시 설정을 사용했으므로 정식 yarn lint 결과는 아닙니다.
- TypeScript 5.9.3·로컬 React/Zustand 선언과 임시 Tauri 선언으로 앱 소스 strict·미사용 변수 검사 통과. 정식 의존성 기반 검사와 UI 테스트는 미실행입니다.
- 실제 상태·시간·터미널 선택 코드를 실행한 임시 Node 하네스 7개 통과. 자동 탐색과 수동 지정의 충돌, 최신 상태 보존, 경로별 기본 터미널, 시각 변환을 확인했습니다.
- 실제 Rust 버전 검사 함수를 추출한 하네스 3개 통과. 정상 출력, 큰 출력의 파이프 배출과 저장 크기 제한, 비정상 종료를 확인했습니다. 실제 AI CLI·Tauri 연결은 제외합니다.
- 기존 Windows Node shim 검사 9개 통과. 추가한 Vitest UI 회귀 검사와 Cargo 전체 테스트는 npm 연결 권한 오류·chrono 캐시 부재로 실행하지 못했습니다.

## 남은 검증

- CI에서 SonarJS S2201 초기화 오류가 보고되었습니다. TypeScript 전이 의존성과 ESLint·SonarJS 버전을 고정했으나 해결 여부는 아직 확인하지 못했습니다. 인지복잡도 상한은 5입니다.
- 로컬 Cargo 1.99.1 설치를 확인했습니다. Cargo test는 chrono 캐시 부재와 crates.io 연결 차단으로 실행하지 못했습니다. 전체 린트·타입 검사·Vitest·Rust 검사 및 Windows EXE·macOS APP 빌드 결과는 미확인입니다. 최종 판단은 수동 Actions 결과를 기준으로 합니다.
- 실제 OS에서 외부 터미널 표시·출력·종료 코드, AI CLI 인증·승인 거부, 트레이 숨김·복원·종료, 동시 예약·중복 방지, 절전·시간 변경·missed 복구, 저장 실패·손상 복구, 알림·Automation 권한을 확인해야 합니다.
- Portable 이동 실행, WebView2 미설치 환경, macOS ARM64/x64 실행, 서명·공증은 미검증입니다. Warp는 설치 탐지만 지원하며 실행은 지원하지 않습니다.
- 전체 앱 CPU·메모리 성능은 측정하지 않았습니다. 실제 의존성 설치로 Yarn/Cargo 잠금 파일을 생성·커밋하고 재현 빌드를 확인해야 합니다.
