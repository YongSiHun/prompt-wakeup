# 검증 현황

기준일: 2026-11-20. Windows 로컬 소스 기준이며 실제 AI CLI 인증·호출 결과를 의미하지 않습니다.

## 정리 및 동작 변경

- 예약 이름 중복을 허용하고 기본 이름을 `새 예약 작업`으로 고정했습니다. 수정·취소·실행은 UUID로 구분합니다.
- 삭제·예약 취소 확인을 `ConfirmButton`으로 합치고, IPC와 감시 루프의 블로킹 작업·오류 변환을 공통화했습니다.
- 동일하게 동작하던 CLI 어댑터·매크로를 종류별 실행 인자 구성으로 통합했습니다. 외부 터미널 모델·설정·상수와 단순 전달용 UI 함수, 자동 번호 로직·테스트를 제거했습니다. 기존 JSON의 퇴역 필드는 무시합니다.
- 함수 주석을 UI·IPC·I/O 등 한 줄 설명으로 통일했습니다. ESLint·Clippy의 인지복잡도 상한은 5입니다.
- 본문 16px, 보조 정보 15px, 제목 20/24px의 공통 글자 크기·색상·글꼴을 적용했습니다.
- 실행이력 안내의 상단 여백을 줄이고 완료 표시는 작업명 오른쪽으로 이동했습니다. 하단은 `상태: 성공/실패/실행중`으로 표시합니다.
- 실행 당시 프롬프트는 이력에 보존합니다. 기존 이력에 원문이 없으면 현재 예약 내용을 구분해서 표시합니다.
- 캡처 PNG 3개를 `docs/captures`로 옮기고 README 링크를 수정했습니다. 앱 패키징용 아이콘은 유지합니다.

## 버그·성능·보안 점검

| 항목             | 확인 및 개선                                                                                                                      |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| 출력 조회 비용   | 파일 전체를 매초 읽던 경로를 최근 256KiB 조회로 제한했습니다. UTF-8 시작 경계를 보정하며 원본 출력 파일은 보존합니다.             |
| 이력 화면 부하   | 최신 20개부터 표시하고 더 보기로 추가 조회합니다. 숨겨진 과거 이력에는 출력 폴링을 만들지 않습니다.                               |
| 비동기 응답 경합 | 기록 전환 시 이전 출력을 지우고 늦게 도착한 이전 응답을 무시하는 회귀 검사를 추가했습니다.                                        |
| 저장 설정 검증   | 저장소 로드 시에도 설정을 검증해 비정상 보존 기간으로 인한 날짜 계산 오류를 차단합니다.                                           |
| OS 명령 탐색     | 접근 권한 설정에 쓰는 `icacls.exe`를 시스템 절대 경로로 실행합니다.                                                               |
| UI 응답성        | 종료 시 디스크 저장을 블로킹 작업 스레드에서 처리합니다.                                                                          |
| 기존 보안 경계   | 프롬프트 stdin 전달, 셸 인자 제한, UUID 경로 검증, HMAC 서명·만료, 중복 실행 방지, 실행 중 이력 삭제 차단 회귀 검사를 유지합니다. |

## 검사 결과

- TypeScript·ESLint(SonarJS 인지복잡도 ≤5) 통과.
- Vitest 67개, Windows shim 9개, Cargo 45개 통과.
- 소스·테스트·문서·설정 Prettier, Rust fmt·Clippy(인지복잡도 ≤5), Vite 프로덕션 빌드 통과.
- 전체 폴더를 순회하는 Prettier 명령은 과거 artifacts 임시 폴더의 접근 권한으로 실패하여 검증 대상을 명시했습니다.

## 검증 범위와 제한

- 브라우저 접근 호스트가 동작하지 않아 실제 화면 캡처를 통한 배치 검증은 완료하지 못했습니다. UI 동작은 Testing Library로 검증했습니다.
- 실제 CLI 로그인·사용량 제한·네트워크 실패와 트레이·절전·macOS 실행, 최종 배포 패키지는 통합 검증하지 않았습니다.
- 의존성 보안 공지 전수 대조는 수행하지 않았습니다. 이번 보안 점검은 저장소 소스와 회귀 검사 범위입니다.
- 원본 출력은 전체 보존하므로 디스크 사용량은 출력 크기와 보존 기간에 따라 늘어납니다.
- 과거 임시 검증 폴더의 재귀 삭제는 자동 승인 정책으로 차단되어 수행하지 않았습니다.
